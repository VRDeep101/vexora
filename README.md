# VEXORA Landing Page

A single-page cyberpunk hero built with React, Vite, and regular CSS.

## Run locally

1. Extract the project ZIP.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed in the terminal.

## Main features

- Neon city background with fog, ambient glow, and animated particles.
- Transparent VEXORA wordmark PNG layered behind the character.
- Staggered intro: loading screen, wordmark reveal, character reveal, then hero copy.
- Cursor-based parallax with different movement amounts for the city, ring, title, and character.
- Compact Join Us button and hover-only navbar underline.
- Responsive mobile navigation and reduced-motion support.

## Assets

Place the following files in `src/assets/`:

- `city-bg.png`
- `char.png`
- `vexora-text.png`

The character and wordmark assets should have transparent backgrounds for the cleanest layering.
